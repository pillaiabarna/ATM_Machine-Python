# ATM_Machine-Python
A simple ATM Machine program developed using Python.

## About the Project
A beginner-friendly ATM Machine simulation developed using Python. This project demonstrates basic banking operations through a menu-driven program.

## Features
- Check account balance
- Deposit money
- Withdraw money
- Insufficient balance checking
- Exit the ATM system

## Technologies Used
- Python 3

## How to Run
1. Download the Python file.
2. Open it in VS Code.
3. Run the program.
4. Enter your initial balance.
5. Select an operation from the menu.
